# 나라별 목표 재산출 결과 (light + 긴급 조달 1.0배)

2026-11-19 · Claude

결론: 새 경제에 맞춰 경제 목표를 다시 뽑으면 나라 간 난도 차이는 줄어든다. 하지만 자원국은 여전히 아무것도 안 해도 목표의 80% 이상을 채운다. 원인은 목표값이 아니라 '경제 성장' 점수의 계산 방식이다. 자산 증가를 재는 방식이라, 물건을 팔지 않고 쌓아 두기만 해도 점수가 오른다.

## 설계 (실행 전에 정함)

- 조건 A: v17 엔진, 운영 자원 `none`. v12 이후 엔진 변화만 보는 대조군이다.
- 조건 B: v17 엔진, `light` + 긴급 조달 1.0배(연료 30G, 광물 20G).
- 보정 게임: 시드 90000~90059. 전체 정상 1판 + 원래 6개국이 각각 투자 중심·무역 중심인 판. 조건마다 780판이다.
- 산출 방법(v15와 같음): 경제 = 자산 증가(투자 45% 인정)의 P75, 최소 50, 5G 단위 올림. 산업 = P75 이상에서 실제 관측된 가장 작은 생산 능력 증가율.
- 검증 게임(조건 B): 정상 시드 130000~130099(100판), 나라별 무행동 시드 132000~132029(6×30판).
- 성공 기준:
    - C1 무행동 학생의 경제 목표 달성비 평균이 6개국 모두 0.8 미만
    - C2 정상 플레이의 경제 목표 달성률이 나라 간에 v15 목표보다 고르다
    - C3 산업 목표도 같은 기준이고, 모든 나라가 1판 이상 달성한다

새로 돌린 게임은 1,840판(A 780, B 780, 검증 280)이다. 실패는 없었다.

## 결과

조건 A의 목표는 v15 목표와 6개국 모두 똑같이 나왔다. 엔진이 바뀐 영향은 없다는 뜻이다. 아래 차이는 모두 운영 자원 규칙에서 온다.

| 나라 | 경제 목표 v15 → B | 정상 플레이 달성률 v15 → B | 무행동 달성비 v15 → B | 정상 플레이 자동 수입 / 새 목표 |
| --- | --- | --- | --- | --- |
| 트로피아 | 305 → 245G | 0% → 19% | 0.30 → 0.38 | 0.72 |
| 그레니아 | 265 → 205G | 0% → 21% | 0.30 → 0.38 | 0.86 |
| 오일리아 | 245 → 285G | 83% → 39% | 0.92 → 0.79 | 0.62 |
| 메카니아 | 230 → 160G | 9% → 71% | 0.11 → 0.16 | 1.11 |
| 미네리아 | 185 → 245G | 77% → 33% | 1.10 → 0.83 | 0.73 |
| 테크니아 | 895 → 880G | 20% → 24% | 0.23 → 0.24 | 0.21 |

- 산업 목표는 6개국 모두 v15와 같게 나왔다. 정상 플레이 달성률은 그레니아 32%부터 메카니아 100%까지 차이가 크다.
- 기준 판정:
    - C1 실패: 미네리아 0.83
    - C2 통과: 달성률 범위 0.83 → 0.52
    - C3 실패: 산업 목표가 그대로라 범위도 그대로(0.68)다. 모든 나라 1판 이상 달성은 통과다.

## 추가 확인: 자동 수입을 빼면? (새 게임 0판, 재채점만)

경제 성장에서 자동 국가 수입을 빼고 같은 방법으로 목표를 다시 뽑아 봤다. 기준 C1·C2는 위와 같다. 결과는 더 나빠졌다.

- 무행동 달성비: 트로피아 0.80, 그레니아 0.93, 미네리아 0.99
- 정상 플레이 평균 달성비: 그레니아 0.28, 메카니아 0.29

활발히 사고팔고 투자한 나라보다 아무것도 안 한 나라가 더 높았다. 무행동 국가는 팔지 않은 생산품이 재고 가치로 쌓이기 때문이다. 정상 국가는 필요한 물건을 수입해 쓰고(소비되면 자산에서 빠진다) 투자금의 55%를 잃는다. 이 방안은 채택하지 않는다.

## 판단

- 목표값만 다시 정해서는 '안 해도 목표에 가까운' 문제가 풀리지 않는다.
- 경제 점수가 무엇을 재는지부터 정해야 한다. 학습 목표가 '수출로 돈을 버는 경험'이라면, 다른 나라가 실제로 사 간 금액(수출 매출)처럼 무역 행동에서만 생기는 값을 재는 편이 맞다. 이것은 점수 설계 결정이라 사용자 확인이 필요하다.
- 산업 목표는 따로 봐야 한다. 메카니아는 정상 플레이에서 항상 달성하고 그레니아는 32%만 달성한다.
