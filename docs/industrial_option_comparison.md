# 산업 목표 1번·3번 실험과 비교

2026-11-19 · Claude · 사용자 요청: 1번(대표 산업 레벨 업만 인정)과 3번(현금 문제)을 차례로 시험하고 비교

결론: 1번은 '밀만 올리는' 문제를 고쳤다. 수출 달성도가 떨어진 나라가 없다. 대신 대표 산업 레벨 3 비용(115~185G)을 R2~R7에 모을 수 있는 나라가 테크니아뿐이라 목표 도달률이 낮았다. 3번(레벨 3 비용 할증 없앰)을 더하자 오일리아·미네리아·테크니아는 97~100%에 도달했다. 그러나 트로피아 50%, 그레니아 37%, 메카니아 27%는 아직 낮다. 세 실험 모두 미리 정한 도달률 기준(80% 이상, 나라 간 차이 0.30 이하)은 통과하지 못했다.

## 실험 1번: 대표 산업 레벨 업만 인정

- 바꾼 요인: 산업 능력 15점 = 15 × min(1, 대표 산업 레벨 업 / 2). 대표 산업은 처음 주력 산업이다(트로피아 바나나, 그레니아 밀, 오일리아 연료, 메카니아 기계, 미네리아 광물, 테크니아 전자제품). 목표는 레벨 3 도달이다.
- 학생형 투자: 목표에 닿을 때까지 매 라운드 대표 산업을 계획한다. AI 예비금 없이 투자한다(`sim_lib.MainIndustryStudent`).
- 게임: 나라별 30판(시드 132000~132029). 같은 시드의 정상 게임과 짝지어 비교했다.
- 기준(실행 전 고정):
    - I1 80% 이상 도달
    - I2 만족도 하락 5점 이하, 운영 부족 1라운드 이하
    - I3 도달률 차이 0.30 이하
    - I4 수출 달성도 하락 0.05 이하
- 판정: I2·I4 통과, I1·I3 실패.

## 실험 3번: 레벨 3 비용 할증 없앰

- 왜 이 요인인가: 1번에서 5개국이 R2~R7 동안 레벨 3 비용을 한 번도 모으지 못했다. 투자 시도 자체가 없었다(막힌 시도 0회). 현금은 투자가 닫힌 R8부터 쌓인다. 그래서 문제를 '농업국'만이 아니라 '중반 투자가 너무 비싸다'로 보고, 레벨 3 비용을 레벨 2와 같게 했다(1.5배 할증 없음). 레벨 4의 2배 비용과 광물·기계 조건은 그대로다. AI를 포함한 모든 나라에 적용했다.
- 점수와 학생형 투자는 1번과 같다.
- 게임: 새 비용에서 정상 130판(시드 130000~130099, 132000~132029)과 학생형 나라별 30판.
- 기준: J1~J4는 I1~I4와 같다. J5는 부작용 검사로, AI 정상 플레이에서 원래 6개국 운영 부족 증가 0.5 이하, 만족도 하락 1점 이하다.
- 판정: J2·J4·J5 통과, J1·J3 실패.
- 부작용: 운영 부족은 게임당 0 → 0.05라운드, 6개국 만족도는 95.25 → 94.85였다. AI 정상 플레이의 수출 달성도는 오히려 조금 올랐다(예: 미네리아 0.89 → 0.96, 오일리아 0.91 → 0.97).

새로 돌린 게임은 1번 180판, 3번 310판으로 모두 490판이다. 실패는 없었다.

## 비교

| 나라 | 목표 도달률: A안 / 1번 / 1번+3번 | 수출 달성도 변화(정상 대비): A안 / 1번 / 1번+3번 |
| --- | --- | --- |
| 트로피아 | 87% / 0% / 50% | +0.04 / +0.03 / +0.03 |
| 그레니아 | 67% / 0% / 37% | +0.03 / +0.03 / +0.04 |
| 오일리아 | 100% / 47% / 100% | +0.07 / 0.00 / +0.02 |
| 메카니아 | 90% / 3% / 27% | **−0.17** / +0.01 / −0.01 |
| 미네리아 | 100% / 7% / 100% | +0.04 / +0.08 / +0.02 |
| 테크니아 | 77% / 93% / 97% | **−0.16** / 0.00 / 0.00 |

- A안은 레벨 업 2번(테크니아 3번), 가장 싼 레벨 업부터 하는 학생형 투자, AI 예비금 없음 조건이다(`docs/industrial_levelup_experiment.md`).
- 1번·3번은 대표 산업 레벨 3이 목표다. A안보다 비싼 목표라 도달률을 그대로 비교하면 안 된다.
- 만족도 하락은 세 실험 모두 2.3점 이하, 운영 부족은 0.17라운드 이하였다.

## 판단

- 동기 면에서는 1번이 낫다. 수출에 쓰는 대표 산업을 키우게 해서 수출 달성도가 떨어지지 않는다.
- 3번은 부작용 없이 중반 투자를 가능하게 했다. 오일리아·미네리아는 7~47%에서 100%가 됐다.
- 남은 문제는 트로피아·그레니아(농업국)와 메카니아다.
    - 농업국은 R2~R6 현금이 약 30~75G(1번 실험 평균)라 레벨 3 비용(75G + 광물 1개)을 모으기 어렵다.
    - 메카니아는 기계 레벨 3에 125G와 광물 2개, 2세대 기계가 필요하다.
- 다음 선택지(사용자 결정):
    1. 1번+3번을 기본으로 두고, 대표 산업 목표를 레벨 업 1번으로 낮춘다. 대신 2번째 레벨 업은 등급(예: A등급) 조건으로 쓴다.
    2. 농업국 현금 흐름을 따로 다룬다. 예: 전자제품 구입 부담(트로피아·그레니아 166G).
    3. 메카니아 기계 레벨 3의 광물 조건을 점검한다.
- 어느 쪽이든 결과를 보고 고르는 값이므로, 새 실험으로 사전 기준을 정해 다시 확인한다.
