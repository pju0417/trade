# 확정 규칙 최종 시뮬레이션: 혼합 행동, 학생 3명 vs 6명

2026-11-19 · Claude · 규칙: `docs/RULES_v1.md`

결론: 학생들이 여러 행동을 섞어 해도, 미리 정한 기준 7개(F1~F7)를 학생 3명·6명 모두에서 통과했다. 성실한 학생은 3명일 때 99%, 6명일 때 95%가 A·B를 받았다. 다만 학생이 많아지면 A 비율이 74%에서 54%로 떨어진다. 성실하지 않은 학생이 함께 늘어나 시장이 덜 원활해지기 때문이다. 모두 성실하면 6명이어도 A 83%다.

## 설계 (실행 전에 정함)

- 규칙: 확정 규칙 v1. 수출 목표는 이 경제에서 다시 뽑은 값이다(트로피아 205, 그레니아 155, 오일리아 340, 메카니아 235, 미네리아 315, 테크니아 765G).
- 학생 유형: 학생마다 아래 비율로 무작위 배정했다.
    - 성실 40%: AI처럼 거래하고 대표 산업을 1번 레벨 업
    - 투자 안 함 15%: AI처럼 거래하지만 투자하지 않음
    - 운영 무시 15%: 성실 + 연료·광물을 사 두지 않음
    - 반값 판매 10%: 성실 + 공개 판매가를 기준가의 절반으로
    - 1G 판매 10%: 성실 + 공개 판매가 1G
    - 무관심 10%: 거래도 투자도 하지 않음
- 상황:
    - 학생 3명: 원래 6개국 중 무작위 3개국을 학생이 맡고 나머지는 AI. 600판, 시드 140000~140599
    - 학생 6명: 원래 6개국을 모두 학생이 맡음. 추가 3개국은 AI. 600판, 시드 141000~141599
    - 참고용: AI만 100판, 모두 성실한 3명 100판, 모두 성실한 6명 100판(시드 142000~142299)
- 기준:
    - F1 성실한 학생 A·B 80% 이상(나라별, 3명·6명 각각)
    - F2 다른 학생의 절반 이상이 성실하지 않은 게임에서도 성실한 학생 A·B 70% 이상
    - F3 평균 종합 점수가 성실이 가장 높고 무관심이 가장 낮음
    - F4 성실보다 A 비율이 높은 유형 없음
    - F5 무관심이 아닌 나라(9개국)의 식량 부족이 나라당 0.2라운드 이하
    - F6 성실한 학생의 평균 점수 차이(6명 대 3명) 3점 이내, A·B 비율 차이 0.10 이하
    - F7 무관심 학생 D 90% 이상

새로 돌린 게임은 1,500판이다. 실패는 없었다.

### 성실한 학생은 주변 학생에게 얼마나 영향을 받나

| 성실하지 않은 다른 학생 수 | 3명: 평균 점수 (A·B) | 6명: 평균 점수 (A·B) |
| --- | --- | --- |
| 0명 | 92.8 (100%) | 93.5 (100%) |
| 1명 | 91.8 (99%) | 91.3 (99%) |
| 2명 | 90.8 (97%) | 90.4 (98%) |
| 3명 | — | 89.6 (97%) |
| 4명 | — | 88.4 (93%) |
| 5명 | — | 87.0 (85%) |

- 성실하지 않은 학생이 한 명 늘 때마다 성실한 학생의 점수가 약 1점씩 내려간다. 같은 수일 때는 3명·6명의 차이가 거의 없다. 6명일 때 점수가 낮은 이유는 성실하지 않은 학생이 평균 1.8명에서 3.6명으로 늘기 때문이다.
- 모두 성실하면 6명이어도 92.5점, A 83%다(3명은 92.8점, A 87%).
- 나라별로는 6명일 때 그레니아(A·B 89%), 미네리아(91%)가 주변 영향을 더 받았다. 나머지는 97~100%다.

### 밀어주기와 경제 상태

- 반값·1G로 파는 학생이 옆에 있을 때 성실한 학생의 점수는 오히려 낮았다(3명: 90.7점 대 92.1점, 6명: 88.9점 대 90.9점). 싸게 팔아 남을 크게 이롭게 하는 효과는 보이지 않았다.
- 식량 부족(무관심이 아닌 나라)은 나라당 0.03~0.04라운드로 거의 없었다.
- 운영 부족은 나라당 3명일 때 0.35일, 6명일 때 0.67일이다. 대부분 운영 무시 학생에게서 나온다.
- 거래량은 AI만일 때 게임당 201개에서 학생 3명일 때 189개, 6명일 때 180개로 줄었다.
- 학생 3명일 때 AI가 맡은 원래 나라들은 평균 86.1점(A·B 72%)이었다. AI만일 때는 88.2점이다.

## 수업에 주는 시사점

- 규칙이 학생 수에 크게 흔들리지 않는다. 성실한 학생은 3명이든 6명이든 대부분 A·B다. 무관심은 항상 D다.
- 운영 무시는 3명일 때 91%가 A·B다. 생활 점수 감점이 있지만 '조금 손해' 수준이다. 수업 중 "연료·광물 정산일" 안내가 필요하다.
- 반값 판매는 성실과 점수 차이가 작다(2~3점). 싸게 팔면 수출 점수가 깎이지만 거래가 늘어 다른 점수가 오르기 때문이다. 손해는 확실하지만 크지 않다.
- 학생이 많은 반에서는 성실하지 않은 학생이 늘수록 모두의 A 비율이 내려간다. 모둠 운영이나 라운드 중간 점검이 도움이 된다.
- 추가 3개국(노비아·아그레아·페리아)에는 수출 목표가 없다. 학생이 7명 이상이면 이 나라들의 목표를 따로 정해야 한다.
- 이 결과는 정해진 행동 유형으로 흉내 낸 것이다. 실제 학생의 협상·실수·학습은 반영하지 않았다.
