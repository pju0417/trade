#11 무역 게임 교차 검증 요청

너는 기존 작성자의 결론을 확인해 주는 역할이 아니라, 독립적인 게임 경제·구현·교육 설계 검토자다.
첨부한 TRADE_GAME_HANDOFF_V17_KO.txt와 코드·근거 묶음을 읽고, ChatGPT가 주장한 결과가 실제 구현과 원본 데이터로 뒷받침되는지 검증해 줘.

[프로젝트]
초등학교6학년 사회 무역 단원의 마무리 게임이다. 현재 학생3명, 목표 수업40분+40분이다. 향후 학생 개별 접속 클라우드 웹앱을 목표로 하지만 현재 검증 자료는9개국·9라운드 Python 경제 시뮬레이터다. 원래6국만 점수를 비교하고 추가3AI는 시장에 참여한다. 규칙은 초등학생이 직관적으로 이해해야 한다.

[검토할 현재 판단]
국가 운영에 연료·광물을 기본 소비시키는 v17 light를 후속 검증 기준으로 추천한 상태다. light는 연료R3·6·9, 광물R4·8에 국가당1묶음씩 사용한다. 최종 수업 규칙 확정은 아니다. electronics_input와 동시에 적용하는 안은 자원국 편중 때문에 현재 추천에서 제외됐다. 이 판단에 동의하도록 유도하지 말고, 유지·수정·철회할 근거를 독립적으로 판단해 줘.

[첫 단계]
1. 전체 프로젝트 구조·상속 경로·데이터 흐름·실제 활성 플래그를 분석해 줘.
2. 사용자 요구, 현재 구현, 검증용 기준, 미채택 후보, 미확인 사항을 구분해 줘.
3. 기존 규칙이나 목표를 바로 수정하지 말고, 요구사항과 현재 동작의 차이 및 영향부터 정리해 줘.
4. 코드가 오류 없이 실행되는 것과 수업 의도대로 기능하는 것을 따로 검토해 줘.

[우선 교차 검증]
- 현재 보관비·생산/판매 비용·판매 수량 추천·재고 제어 중 무엇이 실제 활성화돼 있는가? 비활성이 과거 보류인지 누락인지 근거가 있는가?
- 운영용 자원 필요가 생산·개발 수요와 중복되거나 같은 물품을 두 번 사용하지 않는가?
- 생산이 먼저 원료를 쓰는 순서, 같은 정산일, 인구 비례가 아닌 수요가 의도와 맞는가?
- 부족→만족도→국가 수입이 한 번만 계산되는가? 미래 운영비를 남기지 않는 투자 판단의 영향은 무엇인가?
- v17 비교 점수는 fixed_evaluation.score다. 기존 score와 섞이지 않았는가? steps 검증 기준의 투자자산 45% 인정과 SCORE_TARGETS_V15의 100% 인정 후보를 구분했는가? 후보 메타데이터 1.0을 현행 계수로 잘못 적용하지 않았는가?
- 자원국 우위가 실제 경제 구조·생산 비용·산업 투자·재고 평가·옛 목표 중 어디에서 발생하는가?
- 활용률과 국가 운영 소비를 산업 발전 점수에 넣는 의미가 적절한가? 신규 투자분의 효과를 식별하는가?
- 공개시장1G 최저가, 반값, 투자 중단, 무행동의 정의와360/60 비교 분모가 정확한가?
- 같은 시드 대응 비교, 정상100회/스트레스30회, 국가 평균점수 격차/게임별 격차를 정확히 구분했는가?
- 기본 수입·물물교환·다른 국가의 구매 때문에 무관심 학생이 예상 밖의 이득을 얻는 경로는 없는가?
- 학습 목표(수출·수입, 무역 필요성, 상호 의존)와 학생3명·80분의 설명·조작 부담에 맞는가?

[실행과 증거]
인수인계의 재현 절차와 덮어쓰기 주의사항을 먼저 읽어 줘. 원본은 보존하고 새 검증 코드는 claude_review/ 같은 별도 하위 폴더에 둬. source_v13이나 루트 test_*.py를 추가·수정하면 동결 해시가 달라진다.
작은 묶음은 대형 원본6개를 생략했다. 기존 전체6,740게임의 원장을 검산하려면 전체 증거 ZIP을 받아야 한다. 읽지 못한 파일이나 실행하지 않은 계산은 확인했다고 쓰지 마.
기존 감사기의 PASS를 그대로 인용하는 데 그치지 말고, 가능하면 별도 코드로 현금·자원 수지·점수·대표 거래 사용 경로와 핵심 통계를 재구성해 줘. 기존 감사 재실행, 독립 재계산, 새 게임 실행을 구분해 줘.
새 게임을 실행했다면 조건·시드·완료 수·실패/재시도를 기록해 줘. 코드 실행 환경이 없으면 정적 검토 결과와 미검증 항목을 명확히 분리해 줘.

[출력 형식]
1. 전체 판정: 동의 / 조건부 동의 / 반대 / 증거 부족, 이유.
2. 실제 읽고 실행한 범위와 새 게임 수.
3. 기획·구현 차이 표.
4. 기존 주장 / 독립 계산 / 차이 / 근거의 비교표.
5. 문제 목록: 심각도, 재현 조건, 파일·함수, 경제·학습 영향, 권장 수정.
6. 기존 결론 중 유지할 것·철회할 것·아직 확인할 수 없는 것.
7. 가장 먼저 해결할3가지와 최소한의 후속 비교 실험 설계.

수정안을 제시할 때 국가별1위 횟수를 같게 만드는 것을 목표로 삼지 말고, 생활 유지·합리적인 무역 필요·투자 선택·실제 활용·목표 달성 가능성을 함께 평가해 줘. 한 번에 여러 경제 계수를 바꾸거나 결과를 보고 목표를 맞추지 말아 줘.
