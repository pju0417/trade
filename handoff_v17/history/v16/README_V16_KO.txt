#11 무역 게임 — v16 산업 점수 비교

이번 판단
─────────
산업 점수는 v15 선택안인 생산 능력 15점 + 실제 활용 10점을 유지한다.
국가별 이산 성장 목표, 경제 목표, 투자액 45% 자산 인정, 생산·가격·자원·거래·만족도 규칙을 바꾸지 않았다.
세 변경안은 비교 후보로 보존한다. 부분 연계(B)는 기록 보강 후 재검토할 우선 후보이며 현재 채택한 규칙이 아니다.

먼저 열 파일
────────────
TRADE_INDUSTRY_SCORING_V16_KO.html
  인터넷 없이 브라우저에서 읽는 한국어 검토 보고서다.
  국가별 점수, 전략별 변화, 최저가·무행동의 모든 점수 상승 사례와 한계를 담았다.
  표 수치는 원본 JSON 경로와 연결되어 별도로 검산할 수 있다.
  학생용 게임 화면이나 클라우드 웹앱은 아니다.

무엇을 실행했나
─────────────
v15의 경제 게임 2,180건을 네 점수식으로 재채점했다.
이번에 새로 실행한 경제 게임은 0건이다.
9개 국가, 9라운드이며 기존 6개 국가만 순위에 반영한다.
두 비교경제에서 일반 전략 각 100게임과 별도 전략 검증 조건 각 30게임을 사용했다.
일반 전략 100게임 평균과 전략 검증 30게임 평균을 섞지 않는다.
52,320은 2,180게임 × 6개 평가 국가 × 4개 계산식의 점수 개수다. 게임 횟수가 아니다.
과거에 확인한 결과를 사용하는 후속 비교이며 새로운 독립 표본 검증은 아니다.

비교한 식
─────────
q: v15의 국가별 산업 성장 목표 달성률을 0~1로 제한한 값.
u: 게임 중 자국에서 생산한 물건 중 실제로 한 번 이상 사용된 고유 물건의 비율.

baseline 기존: 15q + 10u
reweight A:    10q + 15u
partial B:    10q + 5qu + 10u
full C:       15qu + 10u

q와 u는 국가 전체 지표다. 특정 투자로 증가한 생산분의 실제 사용을 직접 식별하지 못한다.
B·C도 “늘린 시설이 실제로 쓰인 만큼만 점수를 받는다”는 것을 보장하지 않는다.
초기 지급품은 생산량에서 제외하고, 수입품은 원래 생산국의 활용 성과로 센다.
단순 판매, 재판매, 지속형 상품 반복 사용으로 고유 물건 수가 중복 증가하지 않는다.
기계·전자제품·원료·농산물의 각 단위는 현재 활용률에서 동일한 한 단위다.
보유 미사용 재고 평가액에는 수입품·초기 지급품이 포함될 수 있다.
이 금액을 자국 생산량−사용량으로 해석하지 않는다.

재현 방법
─────────
Python 3.10 이상 표준 라이브러리를 사용한다. 외부 패키지는 필요하지 않다.
압축을 풀고 이 README가 있는 trade_v16 디렉터리에서 아래 명령을 각각 실행한다.
기존 결과를 덮어쓰지 않도록 새로운 reproduced_v16 디렉터리를 사용한다.

python3 test_industry_scoring.py
python3 replay_industry.py --stage freeze --output-dir reproduced_v16
python3 replay_industry.py --stage replay --output-dir reproduced_v16
python3 analyze_industry.py --results reproduced_v16
python3 audit_industry.py --results reproduced_v16

위 작업도 과거 기록을 재계산하는 것이며 경제 게임을 새로 실행하지 않는다.
생성 시각과 실행 시간 때문에 manifest/audit 파일 해시는 원본과 다를 수 있다.
입력·식·점수·통계가 같아야 한다. 실행 디렉터리가 이미 존재하면 다른 새 경로를 사용한다.

제공된 결과에서 보고서만 다시 만들 때:
python3 build_industry_report.py

해석의 범위
───────────
낮은 가격으로 더 많은 실제 사용·수출이 이루어진 점수 상승을 모두 악용으로 취급하지 않는다.
투자액 증가·실사용 비증가·점수 상승은 검토 신호이며 투자 낭비의 확정 판정이 아니다.
1위 횟수 균등화나 점수 범위 축소를 공정성의 단독 기준으로 삼지 않는다.
새 점수를 최적화하는 AI 행동, 학생 3명의 학습, 40분+40분 실제 수업,
클라우드 동시 접속과 실시간 거래는 이번 재채점으로 검증하지 않았다.

다음 단계
─────────
다음은 관측 기록 보강을 권합니다. 산업별·생산 라운드별 생산량과 최초 사용량을 연결하고 기본 생산·레벨 증가분·주력 보너스를 구분합니다. 생산 미실현은 예정 생산량과 원료 충족 기록으로, 생산 후 미사용은 재고 연령·주문·가격·구매 예산·미충족 수요 기록으로 나누어 대조합니다. 관련 기록은 원인 후보를 좁히는 자료이며 특정 투자의 인과 효과를 확정하는 지표가 아닙니다. 학생 화면은 목표·실제 사용·남은 물건을 짧게 보여 주는 구성을 권합니다.
이 관측 기록 보강은 다음 단계 제안이며 이번 점수 재채점에서 이미 구현한 기능이 아니다.
