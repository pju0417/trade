#11 무역 게임 — v15 개발 단계 목표·경제력 점수 수정 검증

완료 상태와 선택한 기준 구성
---------------------------
새 정식 경제 게임2180회, 별도 실행 연결 확인6회, 목표 설정 자료780회 재사용을 완료했습니다.
독립 감사10,520,527회 대조에서 불일치0이며 새 정상200개와 스트레스1980개를
68집단·114대응 비교로 분석했습니다. 보정780회는 새로 실행하지 않았습니다.
최종 보고서는 독립 감사와 결과 검토가 끝난 자료만 읽어서 생성합니다.

검증본의 기준 구성은 CANDIDATE_SELECTION_V15.json의 recommended_view="steps"입니다.
경제력의 뜻은 보유 자산의 성장과 현금 여력으로 유지하고, 투자 자산 인정45%와
이전 v12 경제 목표를 유지하며 산업 목표만 실제 개발 단계로 교정합니다.
기존 공식 점수와 과거 실행 기록을 덮어쓰지 않았고 학생용 앱을 배포하지 않았습니다.

핵심 결과와 판단
----------------
산업 목표 교정은 트로피아·오일리아·메카니아의 반올림 문턱을 바로잡았습니다.
새 정상 실행에서 두 경제 조건 모두 여섯 나라의 목표 달성 실제 경로가 관측됐습니다.
그렇다고 모든 시장에서 달성 가능하거나 나라별 난도가 같다는 뜻은 아닙니다.
개발 단계 교정만으로 평균 게임내 점수 범위는 기존 경제19.28→19.76,
원료+1 조건14.42→14.83으로 조금 커졌습니다. 균형 해결 완료로 해석하지 않습니다.

전액 투자자산 인정+새 경제 목표를 결합하면 단계목표 기준 대비 점수 범위가
기존 경제19.76→21.99, 원료+1 조건14.83→16.20으로 더 커졌습니다.
미네리아의 기존 경제 정상 평균 총점은78.37→77.00으로 낮아졌습니다.
일부 투자 중심 정책의 점수상 이점은 커지고 저투자·무역 중심 정책은 추가로 불리해졌습니다.
따라서 전액 인정 후보는 이번 검증본 기준안에 채택하지 않았습니다.
투자 현금이 설비자산으로 바뀌는 부분의 평가액이 유지되는 항등식은 성립합니다.
개발 때 소비한 원료 등의 재고 변화는 별도로 반영되므로 개발 행위 전체의 자산 불변 보장이 아닙니다.
이를 투자 순간 이익이 새로 만들어지는 것으로 설명하지 않습니다.
원래 경제 목표를 유지한 진단 보기와 새 목표를 적용한 보기를 분리하여
자산 인정의 분자 효과와 경제 목표 변경의 분모 효과를 확인합니다.

단계목표 기준안에서 자국 정상 총점보다 높은 공개1G 판매는1/360,
개발 없는 공개1G는0/360, 무행동은0/360이었습니다.
기준안의1G 예외는 원료+1 트로피아로 실제 사용과 유용한 수출이 늘었습니다.
기존 공식 평가의1G 예외도1/360이지만 기존 경제 메카니아의 다른 기록입니다.
전액 인정 결합 보기에는 정상과 달리 개발에 성공해 능력 점수가 늘어난 미네리아도 있습니다.
예외를 같은 이유로 설명하거나 낮은 가격만 보고 오류·벌점으로 처리하지 않습니다.
무행동의 총점 우위0은 이번 고정 정책·두 경제 조건·시드에서의 관측 결과입니다.

다음 평가 문제는 생산 능력15점과 실제 활용10점의 보상 관계,
그리고 산업 목표 달성 이후 추가 성장과 실제 사용을 보여 주는 방법입니다.
결과를 보고 새로운 보정 계수를 추가하지 않았습니다.

이번에 비교하는 두 변경
----------------------
1. 산업 목표를 실제 개발 단계에 맞춥니다.
   기존 v12의 원75백분위수 이상인 실제 보정 자료의 성장 단계 중 가장 작은 값을 사용합니다.
   0.05 단위로 올림하지 않습니다. 트로피아1/3, 그레니아2/5, 오일리아5/6,
   메카니아5/12, 미네리아3/5, 테크니아3/2입니다.
   모든 나라의 개발 횟수나 최고점 횟수를 같게 맞추는 방식이 아닙니다.
2. 투자 지출의 자산 인정 비율을45%에서100%로 바꾸는 후보를 비교합니다.
   후보 자산 증가 = 기존 자산 증가 + 투자액의55%입니다.
   현금 지출·원료·기계·생산 능력·자동수입·재고 평가는 그대로입니다.
   연구·개발 비용 전액을 인정하는 게임 내 장부 규칙이며 실제 회계 기준이나 청산가가 아닙니다.

평가 보기
---------
주 비교는2×2 조합입니다.
targets       이전 산업·경제 목표, 투자45% 인정
steps         개발 단계 산업 목표, 이전 경제 목표, 투자45% 인정
capital       이전 산업 목표, 새 경제 목표, 투자100% 인정
steps_capital 개발 단계 산업 목표, 새 경제 목표, 투자100% 인정

대조·진단 보기 두 가지를 추가합니다.
legacy             기존 공식 목표·공식 점수를 보존하는 대조군
capital_fixed_goal 개발 단계 산업 목표, 투자100% 인정, 이전 경제 목표 유지

capital_fixed_goal은 자산 인정과 경제 목표 변경 효과를 분리하기 위한 진단용입니다.
여섯 보기의 채점을 여섯 배의 새 경제 게임으로 세지 않습니다.
경제 성장20·예비자금5·능력15·실제 활용10·만족도25·무역25의 배점은 유지합니다.
추가3개국은 종합 점수None이며 원래6개국만 종합 평가합니다.

목표 설정과 검증 자료 분리
-------------------------
목표는 기존 v12 보정 실행780개에서 정합니다. 신규 보정 게임은 없습니다.
국가별 정상·해당 국가 투자·해당 국가 무역 각60개를 같은 비중으로 사용합니다.
다른 국가의 정책을 바꾼 결과에서 해당 국가의 기록을 목표 표본에 넣지 않습니다.
새 경제 목표에도 같은75백분위수·50G 하한·5G 단위 올림을 적용합니다.
테크니아1305G 등의 새 목표는 이 방법의 계산 결과이며 최고점 횟수 맞춤 값이 아닙니다.
v13·v14 결과나 이번 정식 결과를 보고 목표를 다시 학습하지 않습니다.

새 실행의 완료 범위
-------------------
9개국·9라운드, 기존 경제와 전자제품 원료+1 후보를 비교합니다.
정상: 각 경제 조건100회, 총200회. 새 시드120000~120099.
행동: 각 조건30회, 총1980회. 새 시드122000~122029.
정식 경제 게임2180회와 별도의 실행 연결 확인6회를 구분합니다.
정상100회와 행동 대조군30회의 평균을 섞지 않습니다.
원래6개국에 대해 최소가·무행동·투자 중심·무역 중심·개발 없는 최소가를 비교합니다.
테크니아 반값과 전 세계 무역 중단 조건도 포함합니다.
AI는 기존 고정 행동 규칙을 사용하고 새로운 점수를 읽어 전략을 바꾸지 않습니다.

행동과 경제력 해석
-----------------
최소가1G 정책은 구매·생활·개발 판단을 계속합니다.
개발 없는 최소가 정책은 개발을 중지하지만 구매·생활 판단은 계속합니다.
무행동은 거래·투자 없이 자동 생산과 운영수입이 남습니다.
실제 의욕 없는 학생의 모든 행동을 대표하는 실험은 아닙니다.
할인으로 실제 사용과 유용한 무역이 늘어난 성과를 가격만 보고 벌점 처리하지 않습니다.
투자 증가·실제 사용 비증가·점수 상승은 검토 신호이며 낭비의 확정 판정이 아닙니다.
자산 증가·경제력 점수·종합 점수·현금 유동성을 각각 구분합니다.

목표 도달 증거의 한계
--------------------
target_opportunities.json에는 기존 보정 자료의 실제 완료 기록과 상세 성공 경로가 있습니다.
투자 중심 정책이 예비자금·생활 보호를 완화한 경우 이를 명시합니다.
정상 최종 기록과 상세 조건까지 남은 경로는 서로 다른 증거 수준입니다.
구조적 최대 능력은 현금·원료·기계 제약을 완화한 상계이므로 경제적 달성을 보장하지 않습니다.
새 정상 실행의 전체 상세trace는 실제 경제 조건에서의 목표 달성 경로 확인용입니다.
관측한 경로는 그 정책·시장 조건에서의 사례이며 모든 시드의 성공 보장이 아닙니다.

교실 적용 범위
--------------
학생에게는 자기 나라의 목표, 이번 선택으로 달라진 실제 성과, 다음 선택을 짧게 보여 줍니다.
백분위수·자산 인정 계산을 학생의 추가 과제로 만들지 않습니다.
학생3명·AI6개국,40분+40분 수업의 이해도·협상·진행 속도·동시 접속은 이번 범위가 아닙니다.
HTML은 검증 결과를 읽는 정적 보고서이며 학생 접속용 게임이 아닙니다.

파일과 재현 안내
----------------
TRADE_SCORE_REVISION_V15_KO.html       최종 한국어 보고서
CANDIDATE_SELECTION_V15.json          검증본 기준 구성(steps)과 선택 근거
SCORE_REVISION_PROTOCOL_V15.json       사전에 고정한 실행·비교 범위
SCORE_TARGETS_V15.json                 여섯 보기와 고정 목표
target_opportunities.py/json          개발 단계 목표·실제 보정 경로 검증
revised_scoring.py                    경제 실행 후의 순수 재채점
run_score_revision.py                 별도 확인·동결·정식 실행
analyze_score_revision.py             저장 결과의 집계·대응 비교
audit_score_revision.py               원자료·점수·원장·개발·경로의 독립 감사
build_score_revision_report.py        독립 감사와 선택 근거가 있는 결과만 보고서로 생성
validate_score_revision_report.py     보고서 표시 숫자를 원시 결과에서 독립 검산
source_v13/                           보존한 원85개 소스
calibration_input/                    재사용한780개 목표 보정 기록·상세trace
score_revision_results/               정식 결과·원장·266개trace·분석·감사

아래 명령은 이 파일이 있는 폴더에서 실행합니다.
기존 완료 파일을 보존하려면 복사본에서 실행하거나 새 출력 경로를 사용합니다.

기존 결과로 보고서를 재생성하고 새 검산 영수증을 만듭니다.
python3 build_score_revision_report.py
python3 validate_score_revision_report.py --output report_numeric_qa_recheck.json

경제 게임을 실행하지 않고 목표와 점수식을 재검산합니다.
python3 target_opportunities.py --output target_opportunities_recheck.json
python3 revised_scoring.py --output SCORE_TARGETS_V15_recheck.json
python3 audit_score_revision.py --output independent_audit_recheck.json

경제 실행 자체를 재현하려면 기존 결과가 없는 새 폴더를 사용합니다.
아래 작업은 새 경제 게임을 실제로 실행하며 점수만 재계산하는 작업과 다릅니다.
python3 run_score_revision.py --stage smoke --output-dir score_revision_reproduction
python3 run_score_revision.py --stage freeze --output-dir score_revision_reproduction --test-receipt scorer_tests.json
python3 run_score_revision.py --stage formal --output-dir score_revision_reproduction
python3 analyze_score_revision.py --results score_revision_reproduction

새 실행 폴더의 manifest에는 실행 시각 등이 새로 기록됩니다.
목표를 바꾸거나 기존 완료 결과를 덮어쓰는 명령은 아닙니다.
